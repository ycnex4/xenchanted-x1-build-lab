# XXXL Rust Clippy Warning Cleanup

Status: COMPLETED.

This stage turns the Rust/SVM clippy baseline into a strict warning-clean baseline for the current XXXL runtime scaffold.

## Baseline

Before this stage:

- cargo fmt --check passed
- cargo test passed
- cargo clippy --all-targets exited 0
- cargo clippy --all-targets -- -D warnings failed

The strict clippy failure had two categories:

1. Solana entrypoint macro unexpected_cfgs warnings:
   - custom-heap
   - custom-panic
   - target_os = solana

2. One local clippy warning:
   - clippy::needless_lifetimes

## Changes

### Local code cleanup

The local clippy::needless_lifetimes warning was fixed in the runtime CPI helper code.

### Solana entrypoint macro warning policy

A crate-level allow was added:

    #![allow(unexpected_cfgs)] // Solana entrypoint! macro emits custom cfgs under host clippy/rustc check-cfg.

This is intentionally scoped to the Rust compiler unexpected_cfgs lint generated by the Solana entrypoint macro under host clippy/check-cfg.

It does not suppress clippy warnings generally.
